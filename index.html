Master’s project / Universität Bremen · ITEM.IDS

Extended Bit-Plane
Compression

A VHDL hardware decoder for compressed neural-network weights.

Memory transfers place a significant burden on neural-network accelerators. This project explores a lightweight, lossless compression approach: encode 8-bit weights in Python, then reconstruct them in hardware using a synthesizable VHDL decoder.
